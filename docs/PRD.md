# CHMarkDown 产品需求文档

## 1. 产品概述

CHMarkDown 是一个本地运行的 Windows Markdown 笔记工具，用于快速记录、预览和管理 Markdown 内容。

第一版为单用户、本地版，不需要账号和网络。

## 2. 核心功能

用户可以：

- 新建笔记
- 编辑笔记标题和内容
- 删除笔记
- 使用 Markdown 编写内容并实时预览
- 在编辑区与预览区之间双向定位
- 插入或粘贴本地图片
- 调整图片显示尺寸
- 导出 Markdown 文档和关联图片
- 查看笔记标题、内容摘要和最后修改时间

## 3. Markdown 支持

- 标题
- 加粗和斜体
- 列表
- 引用
- 代码块
- 链接
- 图片

## 4. 验收要求

- 应用启动后直接进入笔记界面
- Markdown 可以正常编辑和预览
- 笔记可以新建、保存和删除
- 本地图片可以插入、粘贴、预览和导出
- 原始图片移动后，应用中的图片仍能显示
- 重启应用后笔记和图片不会丢失
- 未保存修改在切换笔记或关闭应用时得到确认
- 保存或读取失败时显示用户可感知的提示

## 5. 数据要求

- 所有数据保存在本机
- 笔记使用本地 JSON 文件保存
- 图片由应用统一保存到自己的数据目录
- 渲染进程不直接访问本地文件系统
