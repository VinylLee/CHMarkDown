# CHMarkDown 产品需求文档

## 1. 产品概述

CHMarkDown 是一个本地运行的 Windows Markdown 编辑与笔记工具，用于快速记录、预览和管理 Markdown 内容。

第一版为单用户、本地版，不需要账号和网络。

## 2. 核心功能

用户可以：

- 新建笔记
- 打开本地 `.md` 和 `.markdown` 文件
- 保存回原文件或另存为新的 Markdown 文件
- 编辑笔记标题和内容
- 删除笔记
- 使用 Markdown 编写内容并实时预览
- 在列表项末尾按回车自动续行，空列表项回车结束列表；`Ctrl+Enter` 跳到当前行行末换行
- 在编辑区与预览区之间双向定位
- 在分栏模式下拖动分隔线调整编辑区和预览区宽度
- 纯预览模式正文随窗口大小自适应宽度
- 插入或粘贴本地图片
- 调整图片显示尺寸
- 拖动滑块或输入数值调整图片尺寸，调整时面板保持可见、预览实时更新
- 点击预览中的图片后用 `Delete` 或 `Backspace` 删除该图片
- 外部 Markdown 文件中的相对路径图片同样可以调整尺寸
- 导出 Markdown 文档和关联图片
- 查看笔记标题、内容摘要和最后修改时间
- 在左侧文档列表中切换本地笔记和已打开的外部文件
- 从列表关闭外部文件或删除不再需要的本地笔记
- 从最近文件列表、拖放或 Windows“打开方式”打开 Markdown 文件
- 重启后恢复上次打开的文档列表、顺序和当前选中项
- 在当前文档内查找、替换并查看 Markdown 标题大纲
- 文档大纲标题支持折叠与展开，按住 `Shift` 点击箭头可同时操作同一层级的标题
- 在编辑区无选区时按整行复制、剪切，并将行式剪贴板内容粘贴到当前行上方
- 在 Markdown 编辑区使用 `Ctrl+Z` 撤销和 `Ctrl+Y` 恢复修改
- 实时查看当前文档字数
- 预览外部 Markdown 文件的相对路径图片，并将新图片保存到文档旁的 `images/`
- 将本地笔记或外部 Markdown 文件统一导出为 Markdown 或包含图片资源的 ZIP
- 调整浅色、深色或跟随系统主题
- 调整编辑器字体、字号、默认打开模式（默认仅预览）、自动换行和外部图片资源目录名称
- 选择是否显示系统托盘图标，并从托盘恢复窗口或退出应用
- 始终只运行一个应用实例，重复启动时恢复并聚焦现有窗口
- 点击“最近文件”标题折叠或展开最近文件区域
- 拖拽最近文件区域与文档列表之间的分隔条，调整最近文件高度

## 3. Markdown 支持

- 标题
- 加粗和斜体
- 列表
- 引用
- 代码块
- 链接
- 图片

## 4. 验收要求

- 应用启动后直接进入笔记界面
- Markdown 可以正常编辑和预览
- 编辑区无选区时，`Ctrl+C` / `Ctrl+X` 复制或剪切完整当前行；随后无选区按 `Ctrl+V` 时在当前行上方插入该行
- 编辑区存在选区或剪贴板不是由整行复制产生时，复制、剪切和粘贴保持系统默认行为
- 查找支持区分大小写、全词匹配、上一个和下一个，并显示当前位置和总数
- “下一个”和“上一个”分别从编辑器当前光标或选区的下方、上方开始查找，并在边界循环
- `Ctrl+F` 打开查找；查找已打开且没有新的文档选区时再次按下会关闭；`Ctrl+R` 打开替换，替换已打开且没有新选区时再次按下会关闭；`Ctrl+B` 切换文档列表
- Markdown 编辑区或预览区存在非空选区时，`Ctrl+F` 和 `Ctrl+R` 自动用选中文字填充查询并立即计算匹配；即使查找已打开也保持面板开启
- 纯预览模式按 `Ctrl+F` 或 `Ctrl+R` 时先进入分栏编辑模式并保持阅读位置，再执行查找或替换动作
- 替换支持当前匹配和全部匹配，且只修改 Markdown 原文中的准确范围
- 大纲层级和源码标题一致，正文变化后即时更新，点击标题可以定位
- 切换分栏编辑与纯预览模式时保持当前阅读位置和编辑选区
- 分栏中线可左右拖动，编辑区和预览区均保持可见，重启后继续使用上次比例
- 分栏中线支持方向键微调，双击后恢复编辑区与预览区均分
- 笔记可以新建、保存和删除
- 本地 Markdown 文件可以打开、保存和另存为
- 最近文件按最后打开时间排列，并可以移除单条或清除全部记录
- 最近文件标题支持鼠标点击和键盘操作折叠/展开，重启后保持最后状态
- 拖入 `.md` / `.markdown` 文件可以打开，不支持的文件会显示提示
- Electron 32 及以上版本通过官方文件路径接口处理拖放，中文、空格目录不影响打开
- 命令行和 Windows“打开方式”传入的 Markdown 文件可以在现有窗口打开
- 文件已移动、删除或无法读取时不会导致应用崩溃
- 打开外部文件后显示文件名和完整路径
- 打开的外部文件会立即出现在左侧文档列表中
- 可同时保留多个已打开的外部文件并在列表中切换
- 关闭外部文件只移出当前列表，不删除磁盘文件
- 从列表关闭本地笔记时必须确认永久删除
- 取消文件对话框不会改变当前文档
- 本地图片可以插入、粘贴、预览和导出
- 撤销和恢复覆盖键入、删除、剪贴、替换、插图和图片尺寸修改，最多保留 100 步
- 新修改发生在已撤销状态后时清除原恢复分支，撤销和恢复同步还原光标与选区
- 本地笔记和外部文件的新图片统一写为 Markdown 图片语法；已有受管 `<img>` 图片仍可预览，并在导出时转换为 Markdown 图片语法
- 原始图片移动后，应用中的图片仍能显示
- 重启应用后笔记和图片不会丢失
- 未保存修改在切换笔记或关闭应用时得到确认
- 保存或读取失败时显示用户可感知的提示
- Windows 便携版启动到主窗口可见的时间应保持在可接受范围
- 启动性能优化必须使用同机、同脚本的多次测量数据验证，不以单次结果作为结论
- 非首屏功能不得阻塞主窗口加载，多个独立本地文件的恢复应并行执行并保持列表顺序
- 外部文件恢复时读取磁盘最新内容，失效文件只跳过自身并显示提示
- 会话记录损坏时安全启动并显示用户可感知的提示
- 启动优化不能减少已有功能或降低 Electron 安全配置
- 同一版本同时提供单文件快速便携版和解压后运行的轻量下载版
- 轻量下载版必须自带完整 Electron 运行时，不依赖用户电脑预装浏览器内核
- 外部 Markdown 的相对路径图片可以预览；插入或粘贴图片后使用文档旁 `images/` 中的相对路径
- 本地笔记和外部文件始终显示“导出”按钮，导出前必须先保存未保存修改
- 文档没有图片引用时导出 `.md`；存在图片引用时导出 `.zip`，远程图片保留 URL 且不下载
- 导出 ZIP 中的 Markdown 必须能继续引用所附本地图片，同一图片不得重复打包
- 图片缺失、路径越界或压缩失败时显示错误，且不得留下看似成功的导出文件
- 偏好设置保存后立即生效，重启后继续保留
- 默认打开模式支持仅编辑、分栏和仅预览，三种模式之间切换仍保持阅读位置
- 设置文件损坏或读取失败时使用安全默认值，并显示用户可感知的提示
- 深色主题下编辑区、预览区、查找、大纲、设置和确认弹窗清晰可读
- 关闭自动换行后，Markdown 长行可以水平滚动且正文不被改写
- 自定义图片资源目录必须是安全的单层文件夹名称，不允许绝对路径或目录越界
- “显示托盘图标”默认开启；开启后关闭窗口只隐藏，关闭后关闭窗口正常退出
- 托盘图标可以恢复并聚焦现有窗口，托盘“退出”和“文件 > 退出”继续检查未保存内容
- Windows 注销或关机时应用不得阻止系统流程
- 连续启动应用多次只能保留一个主窗口；已有窗口最小化或隐藏到托盘时，重复启动必须恢复并聚焦该窗口
- 通过 Windows“打开方式”再次启动时复用现有实例，并将 Markdown 文件交给现有窗口打开

## 5. 数据要求

- 所有数据保存在本机
- 笔记使用本地 JSON 文件保存
- 外部 Markdown 文件只在用户明确保存时写入原路径或所选新路径
- 最近文件记录保存在本地 `recent-files.json`，只保存路径和最后打开时间
- 会话记录保存在本地 `session.json`，只保存本地笔记 ID、外部文件路径、顺序和选中项
- 偏好设置保存在本地 `settings.json`，只保存经过校验的界面、编辑器和托盘选项
- 分栏比例保存在渲染进程本地存储中，不写入 Markdown 文档或会话文件
- 最近文件折叠状态保存在渲染进程本地存储中，不修改最近文件记录
- 会话记录不得包含未保存的标题、正文或图片草稿
- 图片由应用统一保存到自己的数据目录
- 外部文档新插入或粘贴的图片保存在文档同目录的 `images/` 中
- 渲染进程不直接访问本地文件系统
