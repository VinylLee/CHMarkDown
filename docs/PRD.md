# FlowDesk 产品需求文档

## 1. 产品概述

FlowDesk 是一个本地运行的 PC 端效率工具，用于管理待办事项和记录灵感笔记。

第一版为单用户、本地版，不需要账号和网络。

## 2. 页面结构

应用包含两个主要页面：

- 待办事项
- 灵感记录

用户可以通过左侧导航切换页面。

## 3. 待办事项

用户可以：

- 新增待办
- 编辑待办
- 标记为已完成
- 恢复为未完成
- 删除待办
- 设置截止日期
- 设置低、中、高优先级
- 填写备注

### 验收要求

- 标题不能为空
- 新增后立即显示
- 可以修改和删除
- 完成状态可以切换
- 删除前需要确认
- 重启应用后待办不会丢失

## 4. 灵感记录

用户可以：

- 新建笔记
- 编辑笔记
- 删除笔记
- 使用 Markdown 编写内容
- 查看 Markdown 预览
- 插入本地图片
- 查看笔记标题和最后修改时间

### Markdown 支持

第一版支持：

- 标题
- 加粗和斜体
- 列表
- 引用
- 代码块
- 链接
- 图片

### 验收要求

- 标题不能为空
- Markdown 可以正常预览
- 可以插入并显示图片
- 原始图片移动后，应用中的图片仍能显示
- 重启应用后笔记和图片不会丢失
- 删除前需要确认

## 5. 数据要求

- 所有数据保存在本机
- 应用重启后数据不能丢失
- 图片由应用统一保存
- 保存失败时显示错误提示

## 6. 第一版暂不实现

- 登录注册
- 云同步
- 团队协作
- 消息提醒
- 标签
- 全文搜索
- AI 功能
- 数据导入导出
