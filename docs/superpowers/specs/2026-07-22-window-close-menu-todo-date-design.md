# 窗口关闭保护、中文菜单与待办日期条设计

## 目标

- 窗口关闭、Alt+F4 和菜单退出时复用笔记未保存检查。
- 使用应用内确认弹窗提供“保存并退出”“不保存并退出”“取消”。
- 将 Electron 默认菜单替换为中文菜单，并移除可能绕过保存检查的重新加载入口。
- 在待办页面增加周一至周日的日期条，新建待办默认安排到当前查看日期。
- 保留 `dueDate: null` 的旧数据，并通过“未排期”入口访问。

## 关闭协调

主进程拦截 `BrowserWindow` 的 `close` 事件，通过 preload 暴露的受限 IPC 请求渲染进程检查。渲染进程调用当前页面注册的关闭守卫；保存成功或确认放弃修改后，主进程只放行下一次关闭事件，避免递归。

渲染进程完成关闭监听注册后主动通知主进程。监听注册之前没有可编辑内容，因此该阶段允许窗口直接关闭。

## 日期条

- 使用本地日历字段生成 `YYYY-MM-DD`，避免 UTC 时区偏移。
- 默认选中今天，左右按钮按七天切换到相同星期。
- 日期下方的圆点表示当天存在未完成事项。
- 点击顶部日期文字可展开应用内月历，支持按月、按年跳转；不再依赖新增表单中的系统日期弹窗。
- 新增待办的日期完全由顶部当前日期决定，“未排期”视图则创建无日期事项。
- 日期筛选只发生在渲染进程，不修改现有 JSON 和 IPC 数据模型。
- “未排期”视图显示 `dueDate === null` 的事项。

## 安全边界

- 保持 `contextIsolation: true` 和 `nodeIntegration: false`。
- 渲染进程只通过 preload 注册关闭请求监听并返回布尔决策。
- 主进程校验 IPC 消息发送者、请求编号和参数类型。
