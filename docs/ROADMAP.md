# CHMarkDown 开发路线图

## 1. 文档目的

本文档用于规划 CHMarkDown 后续版本的开发顺序。

执行规则：

- 严格按版本顺序开发
- 每次只实现一个版本
- 当前版本通过测试、构建和功能验收后，再进入下一个版本
- 路线图只定义目标和边界；开始某个版本前，再补充详细技术方案
- 不提前实现后续版本功能

## 2. 当前基线：v1.0.1

当前已完成的功能和历史变更记录请参见：

- `PROJECT_OVERVIEW.md` — 完整版本历史、验收记录和实现细节
- `TECH_DESIGN.md` — 技术架构和设计方案

## 3. 版本规划

### v1.0.2：编辑体验增强

#### 目标

提升 Markdown 编辑的流畅度，重点改善列表输入和图片尺寸调整的交互体验。

#### 开发范围

- 列表自动续行：输入列表项后按回车，自动在新行添加列表符号（`-`、`*`、`1.` 等）；再次按回车（空列表项）删除符号并结束列表
- 图片尺寸调整优化：调整尺寸的控制面板保持可见，不因交互而意外关闭，提升调整过程的丝滑感

#### 验收标准


- 在 `- ` 列表项末尾按回车，新行自动以 `- ` 开头
- 在 `1. ` 有序列表项末尾按回车，新行自动以 `2. ` 开头并递增编号
- 在空的列表项（仅含列表符号）按回车，删除该行列表符号并结束列表
- 非列表段落的回车行为不受影响
- 图片尺寸调整面板在拖动过程中保持可见，不意外关闭
- 调整完成后面板可正常关闭
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不支持嵌套列表缩进快捷操作
- 不改变图片插入或导出逻辑

---

### v1.0.3：视图默认值与图片调整体验优化

#### 目标

优化图片尺寸调整的交互细节，确保默认视图设置符合用户预期。

#### 开发范围

- 图片尺寸调整 UX 优化：调整过程中图片保持可预览状态，调整结果即时反馈
- 默认视图确认：验证"默认打开模式"设置中预览模式是否为用户预期默认值，如需调整则更新默认值

#### 验收标准

- 图片尺寸调整时图片保持可见并实时反映尺寸变化
- 拖动调整滑块或输入数值时，图片预览即时更新
- 确认默认视图设置符合用户预期后，新安装用户默认进入正确的视图模式
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不实现图片裁剪或旋转功能
- 不改变图片存储和导出逻辑

### v1.0.4：视图与大纲交互增强

#### 目标

优化预览区随窗口尺寸的自适应表现，并支持文档大纲标题的折叠与展开，提升长文档的浏览体验。

#### 开发范围

- 预览页面大小自适应：窗口放大时预览宽度随之放大，窗口缩小时预览宽度随之减少
- 文档大纲标题折叠/展开：点击大标题右侧的箭头，可收起或展开该标题下方的小标题

#### 验收标准

- 调整窗口大小时，预览区域宽度跟随窗口同步变化，不出现内容被固定宽度截断的情况
- 大纲中带子标题的条目显示折叠/展开箭头
- 点击箭头可收起或展开对应标题下的子标题，其他条目不受影响
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不改变大纲的标题提取规则和点击定位行为

---

### v1.0.5：编辑器状态增强

#### 目标

为当前文档提供字数统计，帮助用户快速了解内容篇幅。

#### 开发范围

- 新增字数统计：显示当前文档的字数

#### 验收标准

- 字数统计随正文输入、删除和替换实时更新
- 统计位置显示明确，不遮挡编辑内容
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不提供阅读时长、段落统计等其他统计维度

---

### v1.0.6：标签页管理

#### 目标

为文档标签页提供右键快捷操作与标签栏空白处新建能力，降低切换、关闭和新建文档的操作成本。

#### 开发范围

- 标签页右键菜单：关闭以上标签、关闭以下标签、关闭其他标签、在资源管理器中打开
- 点击标签栏空白处新建文件

#### 验收标准

- 标签页右键菜单提供"关闭以上标签""关闭以下标签""关闭其他标签""在资源管理器中打开"四个操作，执行后当前编辑状态切换到相邻标签
- 关闭操作只影响目标标签对应的文档，其余标签和文档内容保持完整
- 在资源管理系统打开，应该直接打开对应文件所在文件夹的资源管理器路径
- 点击标签栏空白处可新建文件
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不实现标签拖拽排序或固定标签功能

---

### v1.0.7：格式与视图增强

#### 目标

扩展 Markdown 格式支持范围，优化分栏模式下的阅读连贯性。

#### 开发范围

- LaTeX 公式渲染：支持行内公式（`$...$`）和块级公式（`$$...$$`）
- 编辑与预览同步滚动：分栏模式下滚动一侧时自动同步另一侧的滚动位置，保持内容对应关系

#### 验收标准

- 行内公式 `$E=mc^2$` 在预览中正确渲染为数学符号
- 块级公式 `$$\int_0^1 x\,dx$$` 在预览中居中显示并正确渲染
- 嵌套公式和特殊符号（如 `\frac{}{}`、`\sum`、矩阵等）正确显示
- LaTeX 渲染结果通过 DOMPurify 清理，不引入安全风险
- 分栏模式下滚动编辑区，预览区同步滚动到对应内容位置
- 分栏模式下滚动预览区，编辑区同步滚动到对应内容位置
- 同步滚动不影响纯编辑模式和纯预览模式
- 文档内容变化后同步关系仍然正确
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不支持 LaTeX 编辑器工具栏或公式模板
- 不改变 Markdown 导出时的公式格式
- 不实现双向精确行号映射的同步定位

## 4. 暂不进入路线图

以下能力目前不安排版本：

- 登录与账号系统
- 云同步
- 团队协作
- AI 写作
- 在线插件市场
- 后端服务

这些方向只有在本地文件编辑体验稳定后，才重新评估。
