# CHMarkDown 开发路线图

## 1. 文档目的

本文档用于规划 CHMarkDown 后续版本的开发顺序。

执行规则：

- 严格按版本顺序开发
- 每次只实现一个版本
- 当前版本通过测试、构建和功能验收后，再进入下一个版本
- 路线图只定义目标和边界；开始某个版本前，再补充详细技术方案
- 不提前实现后续版本功能

## 2. 当前基线：v1.0.6

当前已完成的功能和历史变更记录请参见：

- `PROJECT_OVERVIEW.md` — 完整版本历史、验收记录和实现细节
- `TECH_DESIGN.md` — 技术架构和设计方案
- 项目根目录 `CHANGELOG.md` — 面向用户的版本变更摘要

## 3. 版本规划

### v1.0.7：格式与视图增强

#### 目标

扩展 Markdown 格式支持范围，优化分栏模式下的阅读连贯性。

#### 开发范围

- LaTeX 公式渲染：支持行内公式（`$...$`）和块级公式（`$$...$$`）
- 编辑与预览同步滚动：分栏模式下滚动一侧时自动同步另一侧的滚动位置，保持内容对应关系

#### 验收标准

- 行内公式 `$E=mc^2$` 在预览中正确渲染为数学符号
- 块级公式 `$$\int_0^1 x\,dx$$` 在预览中居中显示并正确渲染
- 嵌套公式和特殊符号（如 `\frac{}{}`、`\sum`、矩阵等）正确显示
- LaTeX 渲染结果通过 DOMPurify 清理，不引入安全风险
- 分栏模式下滚动编辑区，预览区同步滚动到对应内容位置
- 分栏模式下滚动预览区，编辑区同步滚动到对应内容位置
- 同步滚动不影响纯编辑模式和纯预览模式
- 文档内容变化后同步关系仍然正确
- 自动化测试、类型检查和生产构建通过

#### 本版本不做

- 不支持 LaTeX 编辑器工具栏或公式模板
- 不改变 Markdown 导出时的公式格式
- 不实现双向精确行号映射的同步定位

## 4. 暂不进入路线图

以下能力目前不安排版本：

- 登录与账号系统
- 云同步
- 团队协作
- AI 写作
- 在线插件市场
- 后端服务

这些方向只有在本地文件编辑体验稳定后，才重新评估。
