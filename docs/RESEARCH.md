# FlowDesk 项目调研

## 项目想法

FlowDesk 是一个面向个人办公场景的 PC 端效率工具，第一版主要解决两个问题：

1. 管理日常待办事项
2. 随时记录灵感和想法

## 目标用户

- 经常使用电脑办公的个人用户
- 希望把待办和零散想法放在同一个工具中的用户
- 不需要复杂团队协作，只希望本地使用的用户

## 用户痛点

- 待办事项分散在聊天软件、便签和文档中
- 临时灵感容易忘记
- 普通便签对 Markdown 和图片支持有限
- 一些效率工具功能过多，上手复杂

## 第一版需要实现

- 新增、编辑、完成和删除待办
- 待办支持截止日期和优先级
- 新增、编辑和删除灵感笔记
- 笔记支持 Markdown 编辑和预览
- 笔记支持插入本地图片
- 所有数据保存在本机

## 第一版暂不实现

- 用户登录
- 云端同步
- 手机端
- 团队协作
- 消息提醒
- AI 自动整理
- 标签和全文搜索

## 产品原则

- 操作简单
- 本地优先
- 第一版只做核心功能
- 不提前设计复杂扩展功能
