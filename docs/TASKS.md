# TASKS.md

## 使用规则

- 每次只完成一个阶段
- 当前阶段完成并检查通过后，再进入下一阶段
- 不要提前开发后续功能

## 阶段一：搭建项目

- [ ] 项目可以正常启动
- [ ] 显示“待办事项”和“灵感记录”两个页面
- [ ] 两个页面可以正常切换

完成标准：

- 能打开应用
- 页面切换正常
- 没有明显报错

## 阶段二：实现待办事项

- [ ] 新增待办
- [ ] 编辑待办
- [ ] 标记完成
- [ ] 删除待办
- [ ] 支持截止日期和优先级
- [ ] 重启应用后待办不会丢失

完成标准：

- 可以完整新增、修改、完成和删除待办
- 重启应用后数据仍然存在

## 阶段三：实现灵感记录

- [ ] 新建笔记
- [ ] 编辑和删除笔记
- [ ] 支持 Markdown
- [ ] 支持 Markdown 预览
- [ ] 支持插入图片
- [ ] 重启应用后笔记和图片不会丢失

完成标准：

- 可以正常记录和编辑内容
- Markdown 可以正常显示
- 图片可以插入和查看
- 重启应用后内容仍然存在

## 阶段四：优化和打包

- [ ] 优化基础页面样式
- [ ] 增加必要的操作提示
- [ ] 检查全部功能
- [ ] 打包成 Windows 安装程序

完成标准：

- 主要功能可以正常使用
- 没有明显报错
- 可以安装并启动应用
